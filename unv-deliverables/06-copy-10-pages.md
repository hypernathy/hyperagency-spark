### Section « Naviguer responsable »
**Titre H2** : Respecter le lac et ses règles

**Corps** :
Le Léman est un espace partagé. Bateaux à moteur, voiliers, kayaks, transports lacustres (CGN), pêcheurs professionnels — chacun a sa place à condition de respecter les règles de navigation.

**Rappels essentiels** :
- Respect des vitesses en zone portuaire
- Priorité aux transports professionnels (CGN)
- Distance minimale aux baigneurs
- Signalisation obligatoire de nuit
- Interdiction de rejeter tout déchet

**Ressources** :
- [Office fédéral des transports (OFT)](https://www.bav.admin.ch)
- [Commission internationale pour la protection des eaux du Léman](https://www.cipel.org)

## 📝 Notes pour l'intégration Kadence / Gutenberg

1. **Bloc Cover** (héros avec image de fond + titre + sous-titre + CTAs)
2. **Bloc Groupe** pour chaque section (fond alterné cream / white)
3. **Bloc Colonnes** pour les cartes (3 colonnes desktop, 1 colonne mobile)
4. **Bloc Bouton** pour les CTAs (styles Kadence : primary or / secondary navy)
5. **Bloc Espacement** entre les sections (80px desktop, 40px mobile)

### Palette à appliquer

- Fond hero : **navy** (#0B1F3A) avec overlay 60% sur image
- Fond sections claires : **cream** (#F5F0E8)
- Fond sections foncées : **navy** (#0B1F3A)
- Boutons CTA principaux : **gold** (#C8A44A) avec texte navy
- Boutons CTA secondaires : **lake** (#2E7FA0) avec texte cream
- Liens dans texte : **lake** (#2E7FA0) souligné au hover

### Typographie

- H1 : Bodoni Moda 700, 48px desktop / 32px mobile
- H2 : Bodoni Moda 700, 32px desktop / 24px mobile
- H3 : Bodoni Moda 600, 22px desktop / 18px mobile
